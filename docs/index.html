diff-cover-js: diff coverage for JavaScript and TypeScript

diff-cover-js checks test coverage only on the lines you changed in a pull request or git diff, not on the whole file. It reports line and branch coverage for those lines and can fail CI below a threshold. It reads the lcov.info that Jest, Vitest, nyc and c8 already write, and runs on Node.js. No Python needed.

Quick start npm GitHub

Why diff coverage?

Normal coverage tools measure whole files. Add 10 lines to a 500-line legacy file, cover all 10, and the file is still at a few percent. Set a global threshold and every pull request is judged on code nobody touched.

Diff coverage (also called patch coverage, the term Codecov uses) asks a narrower question: of the lines this change adds, how many do the tests run? In the example above, diff-cover-js reports 100%, because all 10 changed lines are covered. That makes a threshold like 80% fair on old codebases and strict on new code.

Quick start

Install it as a dev dependency:

npm install --save-dev diff-cover-js

Run your tests with an lcov reporter, then compare against your base branch:

# Jest
npx jest --coverage --coverageReporters=lcov
# or Vitest (needs @vitest/coverage-v8 or @vitest/coverage-istanbul)
npx vitest run --coverage --coverage.reporter=lcov

npx diff-cover-js --lcov coverage/lcov.info --compare-branch origin/main --fail-under 80

The command exits with code 1 when coverage on the changed lines is below 80%. Requirements: Node.js 16 or later, an lcov.info file, and a git repository with the base branch available locally.

Features

  • Line coverage on changed linesBlank lines, comments and type-only lines are skipped automatically.
  • Branch coverage on changed linesReads lcov BRDA records and lists lines with untaken branches.
  • Fails CI on a threshold--fail-under 80 exits with code 1 below the limit.
  • Console, HTML, JSON, MarkdownMarkdown for PR comments and job summaries, JSON for bots and dashboards.
  • Uncommitted changes tooCounts committed, staged and unstaged changes by default, so you can check before you push.
  • Merges lcov blocksJest multi-project, sharded or concatenated reports are merged by adding hit counts.
  • Skips tests by default*.test.*, *.spec.*, __tests__, __mocks__ and .d.ts are excluded.
  • CLI, config file or libraryFlags, a .diff-cover-js.json file, or a typed TypeScript API.

FAQ

What is diff coverage?

The percentage of lines added in a change that are executed by your tests. It ignores lines you didn't touch, so legacy code with low coverage doesn't block new work, and new code can't hide behind a high project-wide number.

Is diff coverage the same as patch coverage?

Yes. Codecov calls it patch coverage; the Python tool diff-cover and diff-cover-js call it diff coverage. diff-cover-js gives you the same number locally and in any CI, without uploading reports to a service.

Is diff-cover-js the same as the diff-cover npm package?

No. diff-cover on npm is a separate TypeScript port of Python diff-cover by another author. diff-cover-js is an independent tool focused on lcov reports from the JavaScript ecosystem. See the comparison for the differences.

Do I need Python?

No. diff-cover-js is a Node.js port of the idea behind Python diff-cover, with similar flags. It has two runtime dependencies and runs on Node.js 16 or later.

Which test runners does it support?

Anything that writes an lcov report: Jest, Vitest (v8 or Istanbul provider), nyc/Istanbul, and c8. Cobertura XML is not supported.

Does it work outside GitHub?

Yes. It only needs git, Node.js and the lcov file, so it runs the same in GitLab CI, Bitbucket Pipelines, Jenkins, CircleCI or on your laptop. In CI, fetch enough history to find the merge base (for example fetch-depth: 0 on GitHub Actions).

Can I use it from code?

Yes. It exports getGitDiff, parseLcov and calculateDiffCoverage with TypeScript types:

import { getGitDiff, parseLcov, calculateDiffCoverage } from 'diff-cover-js';

const diffs = getGitDiff('origin/main', '...');
const result = calculateDiffCoverage(diffs, parseLcov('coverage/lcov.info'));
console.log(result.overallPercent);       // line coverage on changed lines
console.log(result.overallBranchPercent); // branch coverage on changed lines, or null

The full flag reference is in the README.
